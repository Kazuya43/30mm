# 30mm

30分タイマー + 振り返りログ。桜井政博さんの「30分で〇×を済ませる!」タイマー術がヒント。

1. 「やること」と「30分での目標」を入力してスタート
2. 30分後(または中断時)に達成度を5段階で評価
3. 「ログ」「グラフ」タブで日ごとの記録やジャンル別の集計を振り返る

## スマホで使う

GitHub Pages で公開: https://kazuya43.github.io/30mm/

- iPhone (Safari): 共有ボタン →「ホーム画面に追加」
- Android (Chrome): メニュー →「ホーム画面に追加」/「アプリをインストール」

ホーム画面から開くとアプリのように全画面で起動し、オフラインでも使えます。計測中は画面が消えないようにしています(対応ブラウザのみ)。

## データ

記録はブラウザの localStorage に保存されます。端末・ブラウザごとに別々で、同期はされません。

## 開発

ビルド不要。`index.html` を開くか、`python3 -m http.server` で配信して確認します。
`sw.js` がアプリ本体をキャッシュするので、ファイルを更新したら `sw.js` の `VERSION` を上げてください。
